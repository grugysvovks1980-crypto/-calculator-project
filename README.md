# Простий Калькулятор

Консольний калькулятор для виконання базових арифметичних операцій.
Навчальний проєкт для вивчення Git, GitHub та Python.

---

## 💻 Опис

Цей проєкт представляє собою простий калькулятор з текстовим
інтерфейсом, який дозволяє виконувати основні математичні операції в
інтерактивному режимі.

---

## ✨ Функціональність

* **Додавання** (`+`): Сума двох чисел.
* **Віднімання** (`-`): Різниця двох чисел.
* **Множення** (`*`): Добуток двох чисел.
* **Ділення** (`/`): Частка двох чисел (з перевіркою ділення на нуль).
* **Піднесення до степеня** (`**`): Обчислення $x^y$.
* **Обчислення остачі від ділення** (`%`): Модуль.

---

## ⚙️ Вимоги

Для запуску проєкту необхідні:
* **Python 3.7** або вище
* **Операційна система**: Windows, macOS, Linux

---

## 🚀 Встановлення та Запуск

Виконайте наступні кроки для запуску програми:

1.  **Клонуйте репозиторій**:
    ```bash
    git clone [https://github.com/ВАШ_GITHUB_ЛОГІН/calculator-project.git](https://github.com/ВАШ_GITHUB_ЛОГІН/calculator-project.git)
    ```
    *(**Змініть**: **`ВАШ_GITHUB_ЛОГІН`** на ваш реальний логін на GitHub.)*

2.  **Перейдіть** у папку проєкту:
    ```bash
    cd calculator-project
    ```

3.  **Запустіть** програму:
    ```bash
    python calculator.py
    ```

---

## 🖥️ Використання

Після запуску програми:
1. Оберіть операцію (`+`, `-`, `*`, `/`, `**`, `%`).
2. Введіть перше число.
3. Введіть друге число.
4. Отримайте результат.
